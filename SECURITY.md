# Security Policy

## Reporting a Vulnerability

Please do not publicly disclose suspected security vulnerabilities before they
have been assessed.

Report security-sensitive findings to:

[digital.humanism.collective@protonmail.com](mailto:digital.humanism.collective@protonmail.com)

When possible, include enough information to reproduce and assess the issue,
such as:

* the affected specification section, profile, implementation, or tooling surface;
* the expected behavior;
* the observed behavior;
* reproduction steps or a minimal test case;
* any known security impact or boundary violation.

## Scope

Security reports may concern the HACP specification, canonicalization and
cryptographic semantics, conformance tooling, repository-maintained reference
implementations, or enforcement-related artifacts.

A passing HACP conformance result demonstrates compatibility with the applicable
conformance target. It does not by itself constitute a security certification of
an implementation or deployment.

## Public Disclosure

Please allow security-sensitive findings to be assessed before publishing
details that could enable exploitation.

General project questions that are not security-sensitive may use the same
project contact address.
